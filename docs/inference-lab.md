# FrontierOS Inference Lab：采样、解码与局部创意模式

**版本：** FrontierOS v2.1  
**目标：** 把模型推理时的“生成物理”变成可测、可回滚、按模型和任务校准的实验层。它负责扩大可达候选空间，但不替代前沿知识、开放谱系、人类品味或现实验证。

## 1. 核心判断

创造力不能只靠 prompt，也不能把 temperature 当作单一旋钮。输出分布同时受以下因素控制：

- 模型的预训练与后训练数据；
- 对齐造成的模式收窄；
- sampler 的截断规则；
- temperature 与随机种子；
- 发散/收敛的上下文结构；
- 候选之间是否共享答案；
- 循环内评估器奖励什么；
- 开放模型能否进行 base/instruct 路由或 activation steering。

Inference Lab 不规定一个永远正确的配置。它维护每个 `模型 × 版本 × 创作域 × 阶段` 的经验 Pareto 前沿。

## 2. 三条证据校准

### 2.1 Min-p 是强候选，不是唯一正解

[Min-p 原论文](https://arxiv.org/html/2407.01082v8)在 AlpacaEval Creative Writing 中报告：

| 配置 | temperature | 胜率 |
|---|---:|---:|
| temperature only | 1.5 | 53.18% |
| min-p=0.1 | 1.5 | 56.54% |

同温度下的正确效果表达是：

- 绝对提升：`56.54 - 53.18 = 3.36` 个百分点；
- 相对提升：`56.54 / 53.18 - 1 ≈ 6.32%`。

不能写成“+6.6pp”。另外，论文的高温创意写作质量实验使用 LLM-as-a-Judge；它支持 min-p 在该设置下更能维持连贯性，不等于已在人类专家盲评中证明跨域优势。

机器可读核验记录见 [`min-p-creative-writing.json`](../data/claims/min-p-creative-writing.json)。

### 2.2 Temperature 的作用依赖任务

temperature 能增加低概率 token 的可达性，但不会自动产生结构新颖性。它可能在短答联想任务上提高远距词汇，在长文本中同时破坏因果、节奏和一致性。系统必须分开报告：

- 单候选新颖度；
- 候选集覆盖；
- 长程连贯；
- 事实与硬约束；
- 真实人评或执行结果。

### 2.3 复杂创意方法不能被简单判为“无效”

[IDEAFix](https://arxiv.org/pdf/2606.00875)显示，直接写入复杂方法名的 prompt 在新颖度和稀有度上经常不如简单、明确的去固着措辞；但论文也报告方法型提示总体优于控制条件，TRIZ 在部分新颖度结果上接近或超过最佳策略。

正确工程结论是：

> 方法名不是算子。把 SCAMPER、C-K、Design Thinking 或 TRIZ 编译成状态表示、变换、触发条件和停止规则后，再做模块消融；不能根据一种 prompt 实现宣布整个方法无效。

## 3. 推理策略矩阵

第一阶段至少比较以下配置；所有配置使用相同任务、美元预算、最大 token、候选数和评审协议。

| 策略 | 建议起始配置 | 目的 | 风险 |
|---|---|---|---|
| greedy/低温 | temperature 0–0.3 | 质量与一致性基线 | 覆盖面窄 |
| temperature only | 0.7 / 1.0 / 1.5 | 测量纯随机扰动 | 高温失真 |
| top-p | 0.9 / 0.95 | 常用截断基线 | 不确定位置仍可能过宽 |
| min-p | 0.05 / 0.1 / 0.2，与温度网格组合 | 自适应候选截断 | 需要 logits 控制；参数不跨模型通用 |
| CreativeDC | 独立发散后再恢复约束 | 扩大结构搜索 | 单域证据；可能轻微损失效用 |
| 独立 seeds | 每个分支不同种子且不共享答案 | 减少锚定 | 只增加随机性时收益有限 |
| 异构模型 | 2–4 个训练谱系 | 扩大分布差异 | 成本与校准复杂度 |
| base/instruct routing | 高熵或创意片段使用 base | 恢复对齐前多样性 | 开放权重与双模型成本 |
| activation steering | persona/trait vectors | 单模型内部多视角 | 模型、层和强度高度特定 |

表中参数只是实验起点，不是默认生产值。

## 4. 标准实验协议

### 4.1 任务分层

至少覆盖三类任务：

1. 短答发散：AUT、命名、标题、概念联想；
2. 长程创作：故事、品牌叙事、视觉方向、产品概念；
3. 约束创意：事实、预算、受众、技术限制同时存在。

不得用短答 DAT/AUT 的结论直接配置长篇写作。

### 4.2 预算控制

- 每个配置至少运行多个独立 seed；
- 比较等候选数、等输出 token 和等美元成本三种口径；
- 保存 sampler、temperature、seed、模型版本和上下文摘要；
- 先盲化候选，再随机左右顺序；
- 任何调参必须在开发集完成，隐藏集只运行冻结配置。

### 4.3 决策指标

每个配置保留向量，而不是一个总分：

\[
I=[Quality,StructuralNovelty,Coverage,Coherence,Constraint,Cost,Latency]
\]

同时关联 FrontierOS 的七维候选结果和真实执行结果。只有当某配置扩大 Pareto 前沿，而不是单纯提高词汇离散度时，才进入生产候选。

## 5. Evaluator 是搜索的一部分

迭代生成会逐渐拟合循环内评估器。《Recipes for Creativity》在一个食谱生成 pilot 中发现，增加轮数本身不改善创意，选择评估器的影响更大；其中小评估器优于大评估器是该实验结果，不能推广成普遍定律。

每次 Inference Lab 实验必须同时运行 [Evaluator Audit](evaluator-audit.md)，检查：

- 长度、润色和自信语气偏见；
- 对反共识和低保真候选的压制；
- 重复评判稳定性；
- 与专家/用户和真实结果的一致性；
- 多轮之后结构簇是否减少。

## 6. 局部创意模式：训练层主线

### 6.1 CreativeInstruct 式 span switch

[CreativeInstruct](https://arxiv.org/html/2608.07460)用 `[StartCreativity]` / `[EndCreativity]` 标记训练文本中的创意片段，使模型学习在局部切换创意模式。论文在其叙事任务中报告语义多样性约 +48%、结构多样性约 +63%，且 70.3% 的人评比较偏好其创造力。

FrontierOS 的研究假设是：

- 事实、约束和收敛部分保持 instruct mode；
- 概念跃迁、类比、关键意象和结构突变才进入 creative mode；
- 记录每次模式切换对后代和执行结果的贡献；
- 使用无标记、全程标记和局部标记三个消融组。

### 6.2 BILLY 式 activation steering

[BILLY](https://arxiv.org/html/2510.10157v2)通过融合 persona activation vectors，在开放模型内部实现多视角控制，并在论文基准中显著降低相对多 Agent 讨论的时延和估算成本。

它只进入开放权重 R&D，不作为通用 Soul 规则。每个模型必须重新寻找：

- 目标层；
- steering 强度；
- 向量组合；
- 对事实、风格和结构的副作用；
- 是否真的改变概念，而非只改变形容词。

## 7. 部署门槛

一种推理策略只有同时满足以下条件才能成为生产默认：

1. 至少两个真实创作域复现；
2. 质量、事实和硬约束没有越过劣化门槛；
3. 新增的是结构簇或执行价值，不只是词汇变化；
4. 在隐藏任务和新时间窗口上仍有效；
5. 至少一种人类判断或现实结果支持；
6. 成本/时延增量在预先声明的预算内；
7. 模型版本升级后重新校准。

否则它只是实验配置，不进入默认 Agent。
